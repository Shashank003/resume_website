# Shashank Agarwal — Resume Website

A responsive single-page resume website made using **HTML5 and CSS3**.

## Files
- `index.html` — Resume sections and semantic markup
- `style.css` — Typography, colors, layouts, animations and responsiveness

## Running locally
Open `index.html` in a browser. No build or installation required.

## Publishing
Push the files to a public GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, your main branch, and the root folder. Save and wait for deployment. Copy the exact website and repository URLs into the assignment report.

## CSS concepts shown
Element selectors, class selectors, ID selectors, CSS variables, Flexbox, Grid, sticky positioning, responsive media queries, hover and focus states, text styling, spacing and borders.

## Source
Resume content was adapted from the resume supplied by the student. No external JS libraries used.
